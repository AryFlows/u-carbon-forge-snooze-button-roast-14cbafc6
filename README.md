One-line roast of an alarm clock that rings at 6 AM on a Saturday, entered in make.fun's **Snooze Button Roast** bounty.

> You had one job: wake me for work. It's 6 AM on a Saturday and you're ringing like overtime is a personality trait.

(115 characters — inside the competition's 1–200 character gate.)

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Stdlib only, no network, no third-party packages.
